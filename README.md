# Интерактивный веб-дашборд

Клиентское приложение для загрузки CSV, обзора данных, сводной статистики и графиков. Бэкенд, база данных и сборка не нужны: страница открывается в браузере и считает всё на стороне клиента.

Страница загружает CSV, считает сводку по столбцам, рисует три графика и фильтрует строки по значению категории.

## Запуск

Нужен любой современный браузер. Сборка не требуется.

Открыть файл напрямую:

```text
index.html
```

Либо поднять локальный сервер из папки проекта (удобно, если браузер ограничивает чтение локальных файлов):

```text
py -3 -m http.server 8080
```

После этого открыть `http://localhost:8080`.

Проверка файлов из папки `csv`:

```text
http://localhost:8080/tests.html
```

Демонстрационная выборка лежит в `csv/sample_data.csv`: 100 строк и 8 столбцов.

## Архитектура

Три файла рядом, без сборщика. Страница подключает их относительными путями: `styles.css` и `script.js`.

- `index.html` — разметка экрана: загрузка CSV, сводка датасета, таблица первых 20 строк, блоки статистики и три графика.
- `styles.css` — оформление и адаптив от узкой ширины.
- `script.js` — чтение CSV в браузере: кнопка и перетаскивание, разбор файла, типы столбцов, сводка, первые 20 строк, аналитика и три графика. Та же функция `inspectCsvBytes` разбирает файл и на странице, и в тестах. Графики рисует Chart.js с публичного CDN.
- `tests.html` и `tests.js` — проверка файлов из `csv`: выборка, пропуски, пустой файл, незакрытая кавычка, картинка, битая строка, текст вместо числа, файл без чисел, точка с запятой и запятая внутри кавычек.

Поток данных задуман так: пользователь выбирает CSV → страница читает текст файла → определяет типы столбцов → заполняет сводку, таблицу, статистику и графики. Повторная загрузка заменяет предыдущий набор, а не дописывает его.

## Ответы на вопросы

### Какие инструменты и модели использовали и почему

Страницу собирал в Cursor, модель Grok 4.7. Ассистент читал файлы проекта, правил их и открывал страницу в браузере, поэтому парсер, тесты и графики оставались в одном `script.js`. Запросы шли по-русски, а код оставался без сборки: HTML, CSS и JavaScript. Графики рисует Chart.js с публичного CDN: задание разрешает библиотеку, и для неё не нужен свой сервер.

### Какие промпты оказались рабочими, а какие — нет

Лучше всего сработал запрос делать задание по шагам и сначала создать только `README.md` и `index.html`. Точные просьбы, например фильтр по категории или ещё 80 строк, тоже давали один нужный кусок. Общая формулировка «сделай задание» без шага смешивала бы файлы, расчёты и оформление. Запрос дописать тестовые данные один раз затянулся, его пришлось повторить конкретнее.

### Что пришлось исправлять за ИИ и как вы поняли, что там ошибка

Длинные подписи категорий заходили на название оси: это было видно на скриншоте диаграммы. Фильтр оставался на экране до загрузки файла, потому что `display: grid` перекрывал атрибут `hidden`. На ширине 360px холст графика растягивал страницу. Звёзды на фоне попадали на текст заголовка. Эти места нашлись при просмотре страницы, а не при чтении кода.

### Что не успели или сделали бы иначе при наличии времени

Фильтр по диапазону числа не делал: в задании он необязательный, и запрос был только про категорию. Тесты проверяют разбор CSV, но не выбор значения фильтра на самой странице. При большем времени добавил бы эту проверку, постраничный показ всей таблицы и круговую диаграмму рядом со столбчатой. Предупреждение о большом файле и выбор нескольких категорий тоже остались за рамками срока.
